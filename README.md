# Homework Classes

Проект для изучения объектно-ориентированного программирования (ООП) на Python.

## Описание проекта

Проект реализует базовую структуру данных для интернет-магазина, включающую:

- **Product** — класс для представления товара с атрибутами:
  - название (name)
  - описание (description)
  - цена (price)
  - количество в наличии (quantity)

- **Category** — класс для представления категории товаров с атрибутами:
  - название (name)
  - описание (description)
  - список товаров категории (products)
  - общее количество категорий (total_categories)
  - общее количество товаров (total_products)

## Функциональность

- Создание товаров и категорий
- Автоматический подсчёт количества категорий и товаров через атрибуты класса
- Добавление и удаление товаров из категории
- Автоматическое обновление счётчиков при добавлении/удалении товаров
