# Homework Classes

Проект для изучения объектно-ориентированного программирования (ООП) на Python.

## Описание проекта

Проект реализует базовую структуру данных для интернет-магазина с использованием принципов инкапсуляции и ООП.

### Класс `Product` (Товар)

Представляет товар с следующими характеристиками:

**Атрибуты:**
- `name` (str) — название товара
- `description` (str) — описание товара
- `__price` (float) — цена товара (приватный атрибут)
- `quantity` (int) — количество в наличии

**Методы и свойства:**
- `@property price` — геттер для получения цены
- `@price.setter` — сеттер с проверкой (цена не может быть ≤ 0)
- `new_product(cls, product_data: Dict)` — класс-метод для создания товара из словаря

### Класс `Category` (Категория)

Представляет категорию товаров с группировкой продуктов.

**Атрибуты:**
- `name` (str) — название категории
- `description` (str) — описание категории
- `__products` (List[Product]) — приватный список товаров
- `category_count` (int) — общее количество категорий (атрибут класса)
- `product_count` (int) — общее количество товаров (атрибут класса)

**Методы и свойства:**
- `add_product(product)` — добавление товара в категорию
- `@property products` — геттер, возвращающий список товаров в виде строки
- `@property products_list` — геттер, возвращающий копию списка товаров
- `get_statistics()` — класс-метод для получения статистики

## Функциональность

-  Создание товаров и категорий
-  Приватные атрибуты (`__price`, `__products`) с геттерами и сеттерами
-  Валидация цены (не может быть нулевой или отрицательной)
-  Автоматический подсчёт количества категорий и товаров через атрибуты класса
-  Добавление товаров в категорию через специальный метод `add_product()`
-  Класс-метод `new_product()` для создания товара из словаря
-  Форматированный вывод списка товаров в виде строки

## Технологии

- Python 3.14
- Poetry — управление зависимостями
- Pytest — тестирование
- Pytest-cov — проверка покрытия кода тестами

## Установка и запуск

### 1. Клонирование репозитория

```bash
git clone git@github.com:your_username/homework_classes.git
cd homework_classes
2. Установка зависимостей
bash
poetry install
3. Запуск тестов
bash
# Запуск всех тестов
poetry run pytest tests/ -v

# Запуск конкретного теста
poetry run pytest tests/test_models.py::test_product -v

# Запуск с отчётом о покрытии
poetry run pytest tests/ --cov=src --cov-report=term-missing
